General query log on Taxila's SIS database server, taxila-db
Teaching copy for the Day 7 lab, floor tier. Every account and value is a prepared sample.

The real file is /var/lib/mysql/kali.log on your Kali virtual machine. In the real file the
Time column starts with the date; it has been removed from this copy, and the times are kept.
The server writes the time only when it changes, so a line with no time happened in the
same second as the line above it. Id is the connection: each sign-in gets a new number.
The first line, a Quit, is the administrator's connection that turned the log on: the
statement that turned it on arrived while logging was still off, so only the sign-out shows.

Questions for the lab, step 7:
  1. Which account made each statement? Use the Id column to join each Query to its Connect line.
  2. Which two statements did the portal account ask for that its grants do not allow?
     The general query log records what was asked, as it arrives, before the server checks it.
     It does not say whether a statement was allowed: compare each one with grants.txt, Part B.
  3. If logging had been off, what would the Data Protection Officer be able to show about this morning?
