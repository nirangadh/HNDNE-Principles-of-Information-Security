Any size in, one size out

A hash function takes an input of any size and returns a digest of one fixed length. Here the hash function is SHA-256, the Secure Hash Algorithm at 256 bits. Its digest is always sixty-four hexadecimal characters. Fingerprint inputs of very different sizes, and watch the length of the digest.
