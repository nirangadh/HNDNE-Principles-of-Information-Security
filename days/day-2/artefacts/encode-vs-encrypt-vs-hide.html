Encode, encrypt, hide

Three different things can make a message look unreadable: encoding, encrypting and hiding. The encrypting here uses the Advanced Encryption Standard (AES). Run the same line through all three. Then try to get it back without a key, and see which one actually protects it.

The encryption on this page uses your browser's own cryptography, called Web Crypto: AES with a 256-bit key, made fresh each time you press Run. The key is never shown in full and never leaves this page. The lines are prepared examples from Taxila College, which is fictional.
