One key, both ways

Symmetric encryption uses one key for both directions: the same key locks and unlocks. Here the cipher is the Advanced Encryption Standard (AES), with a 256-bit key, in cipher block chaining mode. Encrypt a line from an exam paper, then see what the right key and a wrong key do.

This page uses your browser's own cryptography, called Web Crypto. A wrong key is usually refused, because the end of every message carries a few filler bytes of a fixed pattern, called padding, and a wrong key scrambles them. Once in a while a wrong key passes that check by chance and gives nonsense. It never gives the message back, even in part. The key is made fresh on this page and never leaves it.
