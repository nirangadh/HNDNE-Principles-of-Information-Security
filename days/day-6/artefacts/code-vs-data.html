Data or command: the boundary in a form letter

An application fills a blank in a fixed instruction, the way a clerk fills a blank in a form letter. If what you write stays inside the blank, it is data. If it is allowed to run past the blank, it is read as part of the instruction. Choose a prepared value and watch where it lands.
