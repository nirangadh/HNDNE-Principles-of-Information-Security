Stack the factors

Authentication checks evidence of who you are. Each kind of evidence is a factor: something you know, something you have, something you are. Here you see Taxila's sign-in log while a prepared list of leaked email-and-password pairs is replayed against it. This is credential stuffing, seen from the defender's seat.

Waiting for Web Crypto...

The phone and the server share a secret key. Every 30 seconds both compute a keyed hash of the current time, the HMAC you met on Day 3, and turn it into six digits. Both get the same code without talking to each other. A leaked password list holds no phone and no secret key, so it cannot make the code.

All accounts, passwords and results on this page are prepared samples, and no sign-in is sent anywhere. The code above is computed in your browser with its own cryptography, called Web Crypto, using the time-based one-time password method with HMAC and SHA-1 and a demonstration key that protects nothing.
