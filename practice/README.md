# Practice questions

One practice question follows each teaching day. Each question is set somewhere other than Taxila College, so that you practise using the day's ideas in a new setting. Each has three parts that grow in demand: explain an idea, apply it to the setting, then weigh a choice. Answer guidance follows each question; try the question first, in writing, before you read it.

A question appears here when its day's materials are posted.
